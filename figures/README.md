```bash

```

## Generating Figures

**Architecture diagrams** (requires matplotlib):
```bash
python figures/architecture/generate_diagrams.py
```

**GradCAM saliency figures**:
```bash
python experiments/gradcam_vla/code/scripts/multi_scene_validation.py
# Outputs: figures/robot_scene_*, figures/office_scene_*, etc.
```

**ACT training comparison**:
```bash
python experiments/act_modifications/code/analyze_model_predictions.py \
    --checkpoint experiments/act_modifications/results/ \
    --output figures/
```

---

*Note: Large result figures (>1MB) may not be tracked in git. Run the generation scripts above to reproduce them locally.*
